# Komentář k zákonu č. 229/2002 Sb., o finančním arbitrovi

Otevřený komentář k zákonu o finančním arbitrovi — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; působnost arbitra ve sporech spotřebitelů s finančními institucemi, arbitr a jeho zástupce, řízení, nález a námitky, právní moc a vykonatelnost, náklady řízení, informační povinnost a pořádková pokuta.

Konsolidované znění: dokument e-Sbírky `SB-2002-00229_2025-02-15`.
